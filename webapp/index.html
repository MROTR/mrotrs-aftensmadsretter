☑️ Forbind til Microsoft To Do (1-klik oprettelse på iPhone)

Microsoft To Do-appen på iPhone opretter desværre kun én samlet opgave, når man indsætter flere linjer fra udklipsholderen. Her kan du vælge mellem direkte API-synkronisering (opretter hver ingrediens som en separat opgave via Microsoft Graph) eller en iPhone Genvej.

Metode 1: Direkte Microsoft Login (OAuth 2.0 PKCE — anbefalet)

Log ind med din Microsoft-konto direkte i browseren. Kræver et gratis Application (client) ID fra Azure (tager 1 minut at oprette én gang):

  1. Åbn Azure App Registrations ↗ og tryk New registration.
  2. Navn: Aftensmadsretter. Vælg Accounts in any organizational directory and personal Microsoft accounts (eller Personal Microsoft accounts only).
  3. Under Redirect URI: Vælg platformen Single-page application (SPA) og indsæt denne nøjagtige adresse:
  4. Tryk Register, kopiér Application (client) ID, og indsæt det herunder.

Metode 3: iPhone Genvej (Apple Shortcuts → Microsoft To Do-appen uden API)

På iPhone kan du også oprette en genvej i Apples Genveje (Shortcuts)-app med navnet Tilføj til To Do:

  1. Åbn Genveje på din iPhone, tryk + og omdøb genvejen til præcis Tilføj til To Do.
  2. Tilføj handlingen Opdel tekst: Sæt den til at opdele Genvejsinput (eller Udklipsholder) ved Nye linjer.
  3. Tilføj handlingen Gentag med hver (for hvert element i Opdel tekst).
  4. Inde i løkken: Tilføj Microsoft To Do → Tilføj opgave, sæt Titel til Gentagelseselement, og vælg din liste (f.eks. Indkøb).

Når genvejen findes på telefonen, kan du blot trykke på 📲 iPhone Genvej øverst på indkøbslisten — så oprettes alle varer automatisk enkeltvis i Microsoft To Do!
